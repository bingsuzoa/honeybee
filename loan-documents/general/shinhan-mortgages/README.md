# 신한은행 일반 주택담보대출 데이터

기준일: 2026-07-12

## 상품
- `apartment-mortgage`: 신한주택대출(아파트), 상품코드 `S614221100`
- `home-mortgage`: 신한주택대출, 상품코드 `614111100`

각 상품은 `source`, `structured`, `rag`로 구분합니다.

## 중요한 적용 원칙
- 공식 페이지와 신한은행 공통 주택담보대출 상품설명서에서 확인되는 내용만 확정값으로 기록했습니다.
- 실제 한도는 담보평가, LTV, DSR, 소득, 부채, 신용도와 은행 심사에 따라 결정되므로 고정 숫자로 단정하지 않습니다.
- 실제 금리는 기준금리 + 가산금리 - 우대금리 구조이며 고객별로 달라집니다.
- 금융당국의 LTV·DSR·스트레스 DSR 규칙은 은행 상품 데이터와 별도의 공통 규제 데이터로 관리해야 합니다.
